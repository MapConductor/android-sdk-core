# Web Mercator 適合ベクタ。android-sdk / ios-sdk / react-sdk で同一のファイル。
#
# ## これは何か
#
# `zoom-golden.txt` とは別物。あちらは移行前のプロバイダが返した値の記録で、
# 既知の不具合（ios-for-mapbox のオフセット欠落）まで保存している。こちらは
# 「3 プラットフォームの**現在の実装**が同じ答えを出すか」を見るための入力。
#
# provider に依存しない純粋な計算だけを対象にする。provider ごとのカメラモデル
# の差は正当なので、ここには入れない。
#
# ## 形式
#
#   project|<latitude>|<longitude>      緯度経度 -> EPSG:3857 メートル
#   unproject|<x>|<y>                   EPSG:3857 メートル -> 緯度経度
#
# 出力は `%.6f`（マイクロメートル / ナノ度）で揃える。f64 のノイズより十分粗く、
# 実装差より十分細かい。言語ごとの既定の数値表記（Kotlin の 1.49E7 など）を
# 避けるために桁を固定している。
#
# ## 何を狙った入力か
#
# 端の扱いが実装で割れる。極、日付変更線の外側、Web Mercator の定義端
# （±85.05112878）を意図的に含めてある。
